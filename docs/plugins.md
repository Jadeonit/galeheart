# Плагины GaleHeart — рабочий список

Сервер: **Paper 1.21.11**, Java 21, 6 ГБ / 4 vCPU (Rionix GAME-3, Германия).
Аудитория: EN. Модерации на старте нет — ставка на автоматику.

## Принципы отбора

- Максимум ~25 плагинов. Каждый лишний — это TPS, конфликты и обновления.
- Ничего, что дублирует своё: сердца, сезоны, квесты и арена — свои плагины.
- Никаких «анти-лаг» плагинов: они ломают фермы и не лечат причину.
- Всё, что пишет в БД, — только SQLite, без внешних сервисов на старте.

## Что не ставить

- **ClearLag / LagFixer / EntityTrackerFixer** — ломают фермы, эффект нулевой.
- **ChestShop / экономика** — экономика = сердца, вторая валюта размывает смысл.
- **RPG-плагины, кастомные мобы, данжи** — не в эту концепцию.
- **Карты мира** — база должна быть секретом.
- **Автодонат-киты с предметами** — нарушение EULA.

## Проверка перед открытием

- `online-mode=true`, whitelist выключен, античит включён.
- Бэкапы: час, 7 дней, копия вне хоста.
- `/plugins` — нет красных, нет дублей функционала.
- TPS 20.0 на пустом, 19.5+ при 20 игроках.
- Все тексты на английском, включая ошибки и подсказки.
