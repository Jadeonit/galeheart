# GaleHeart — логотип

Стиль: наклонные блочные буквы, пиксельная текстура, светлая верхняя грань,
тёмная глубина вниз, звёздный `SMP`. Всё генерируется скриптом, Blockbench не нужен.

## Файлы

| Файл | Что это |
|---|---|
| `galeheart-wordmark.png` | широкий вордмарк `GALEHEART` + `SMP`, прозрачный фон |
| `galeheart-wordmark-stacked.png` | стек `GALE` / `HEART` / `SMP`, прозрачный фон |
| `galeheart-avatar-512.png` / `-1024.png` | аватарка с тёмным фоном |
| `galeheart-banner-1500x500.png` | баннер под шапку YouTube / X |
| `galeheart-preview.png` | превью 1600×900 |
| `build_wordmark.py` | генератор |
| `blockbench/` | старый вариант 3D-модели, если когда-нибудь поставишь Blockbench |

## Как менять

**Цвета** — `STORM`, `CRIMSON`, `NIGHT` в `build_wordmark.py`, формат `(база, светлое, тёмное)`.

**Буквы** — словарь `FONT`, сетка 9×11, `1` — блок. Можно добавить любые латинские буквы и цифры.

**Наклон и глубина** — `SHEAR` (0.22 = текущий) и параметр `depth` в `compose_wide` / `compose_stacked`.

После правок:

```bash
python build_wordmark.py
```

Пересоберёт вордмарк, стек, аватарки, баннер и превью.

## Размеры

- Вордмарк: 1716×340, буквы 9×11 блоков, глубина 4 блока, наклон 22% высоты.
- Стек: 847×552.
- `SMP` — 8 блоков высотой, звёздная текстура, садится под основной текст с нахлёстом.

## Если нужен другой характер

- Толще/тоньше буквы — правится сетка `FONT`.
- Меньше наклона — `SHEAR = 0.14`.
- Больше глубины — `depth=6` в `compose_*`.
- Другая палитра — три константы вверху файла.
