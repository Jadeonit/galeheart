# GaleHeart

A seasonal no-claims PvP SMP: lifesteal hearts, anomalous weather, quest-gated
dimensions and a duel arena. Paper 1.21.11, Java 21, English-first.

This repository holds everything that runs on the server: our own plugins,
their configs, the season design docs and the brand assets.

## How the systems connect

1. A new player joins, gets **24 hours of full protection** (cannot deal or take
   player damage), a starter kit, and wakes up in the wild 100–250 blocks from
   spawn. The spawn is a small unprotected platform — players may break it or
   build it up.
2. Death costs a heart. The victim drops a **Heart** item, anyone can pick it up
   and right-click it for `+1` heart, up to the cap.
3. Hearts above `8` **cool down**: `-1` every 48 hours without a PvP kill.
4. Completing the **Nether Key** quest grants `galeheart.nether`; PortalBlock
   opens the Nether for that player. Same for the End.
5. Weather anomalies run on a schedule, announced an hour ahead, **at most
   twice a day**.
6. At season end `/season finale` drops everyone to one heart for 30 minutes
   and shrinks the border.
7. Duels never move hearts: `/safepvp` gives a kit, `/pvp` puts your own
   inventory at stake. Both sides must accept.
8. Two to three times a week the leader gets a **bounty**: everyone receives
   a compass that points at them, and the hunter who lands the kill takes a
   heart.

## Build

Every plugin is a standard Maven project:

```bash
cd plugins/galeheart-core
mvn -DskipTests package
```

Requires JDK 21. The jar lands in `target/`.

Builds are also reproducible without Maven: compile with `javac --release 21`
against `paper-api-1.21.11-R0.1-SNAPSHOT` and package the resources with `jar`.
